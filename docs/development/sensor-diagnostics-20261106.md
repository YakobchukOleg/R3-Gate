# WorkMeter SOLO 2.7.2 — sensor wake, diagnostics and object catalogs

Base: verified `ceb45ba` (PR 22). Main is unchanged.

- Replace the runtime accelerometer trigger with a bounded 5-second RMS/activity-fraction window, tolerant of weak samples between steps. Add optional one-shot Significant Motion wake/rearm. Monotonic 60-second probes request GPS every 3 seconds, rearmed no faster than 90 seconds; confirmed movement requests 10 seconds. Sensors remain wake hints; existing GPS quality, arrival dwell, manual priority and workday/private-time gates remain authoritative. Adaptive sensing defaults on only when no explicit preference exists.
- Bounded private JSONL diagnostics (3 days, bounded file sizes and export size) are written on a bounded background queue. Record sensor summaries, GPS quality/rejection/zone/notification events, shared UI button actions, confirmations and manual stage outcomes. No PIN, auth token or typed form values. History survives day close; discarded/overflow events are marked. Export includes old GPS report and device/configuration metadata.
- Verified ZIP snapshots include manifest-protected diagnostics and a whitelisted object catalog. Separate companion files are published locally and uploaded with their own persisted Drive IDs/resumable sessions and checksum verification. Historic diagnostics are restored separately from active GPS state; object GPS is restored by stable ID. Optional attachment restoration failures surface a warning after journal restoration.
- Object-only JSON export/import whitelists ID, TAG, city, address, organization, Maps link, place type, archived flag and GPS point/radius. Notes, materials, photos, time and finance records are excluded. Import previews additions, skips same IDs and rejects conflicting TAG owners; no existing object is overwritten.
- Daily local backup defaults to approximately 21:00 Europe/Warsaw on first launch of this feature; hour is editable. Daily Drive backups are enabled by this user-authorized migration and require an already connected account; routine app launches keep existing scheduled work rather than sliding its initial delay. WorkManager can delay jobs and its periodic 24-hour clock can shift around DST. User-selected persistent SAF folder receives separate ZIP/catalog/diagnostic files; private copies alone do not survive uninstall. Old JSON import remains available, but new local backup entry routes to full ZIP.
- App 2.7.2/code 29, stable existing signing configuration. No uninstall is required for the previously verified same-certificate APK. Other installed certificates need diagnosis rather than blindly uninstalling.

Validation: 33 new JVM cases plus 3 new Android cases cover rolling motion, bounded logs, import isolation, GPS validation, companion integrity and Warsaw/DST scheduling. Full JVM/lint/Android instrumentation must pass on the published head before an APK is accepted. Physical Samsung lock-screen motion, public SAF folder persistence and real Drive reconnection still require phone tests. No speed/battery improvement is claimed as measured yet.
