## First increment

- Home no longer repeats Obiekty, Mój czas and Więcej as large content buttons;
  permanent navigation retains those routes, including the financial PIN gate.
- Label day time separately from stage time; a closed day's retained total is
  explicitly identified as the last day.
- Travel shows `Wybierz cel` without fresh confirmed GPS evidence and
  `Potwierdź przyjazd` when the existing GPS eligibility rule succeeds.
  Existing travel/arrival handlers and confirmations remain authoritative.
- Object search describes supported fields to accessibility services. Arrival
  has one create-object entry using the existing session-aware handler.
- Existing navigation/arrival tests follow the updated visible controls; add a
  JVM regression for evidence-dependent arrival copy.
- Dedicated branch CI runs unit tests, APK assembly, lint and Android 15 tests.
  It preserves the signed test APK, checksum and exact SHA before emulator tests,
  so a later device-test failure remains distinguishable from build failure.

No data schema, identifiers, stored themes, finance logic, GPS collection or
upload handlers were changed. APK version remains 2.7.0, matching the base;
this is a UX test build, not a new public release.
